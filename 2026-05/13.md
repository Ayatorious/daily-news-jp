### [Cisco] Announcing Foundry Security Spec

- **発表日**: 2026-05-12 (火 17:56 JST)
- **カテゴリ**: セキュリティ / Security (AI Security, Artificial Intelligence)
- **影響範囲**: オープンソース仕様の公開 — 適用対象は organization が自前で構築する agentic security evaluation harness。特定製品のバージョン影響範囲は公式発表の確認が必要。
- **核心要約** (本文ベース):
  - **何 (What)**: Cisco が `Foundry Security Spec` をオープンソースとして公開。AI エージェント型セキュリティ評価システム (agentic security evaluation system) を構築するための、モデル非依存 (model-agnostic) / スタック非依存 (stack-agnostic) のブループリント。
  - **どのように (How)**: GitHub の `spec-kit` と組み合わせて利用。2 つの主要アーティファクトで構成 — (1) `spec` アーティファクト: 8 個の core agent role + 5 個の extension role + finding lifecycle + coordination substrate + 約 130 個の functional requirement (各々に inline rationale を付随)、(2) `constitution` アーティファクト: 11 個の不可侵 (inviolable) 原則。Claude Code、Codex などの AI エージェントが `constitution.md` を読み込み、インフラを構築する spec-driven ワークフローを採用。
  - **なぜ・効果 (Why / Impact)**: 従来の "find and patch" サイクルが、攻撃者がマシンスピードで vulnerability を発見する速度に追いつけない dual-front 課題への対応。ノイジーなアラートを検証可能 (verifiable) なセキュリティ findings に転換し、hallucinated findings の問題を回避。
  - **主要データ**: 8 core agent role、5 extension role、約 130 個の functional requirement、11 個の inviolable principle。
- **原文リンク**: https://blogs.cisco.com/ai/announcing-foundry-security-spec
