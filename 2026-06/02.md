### [CNCF] Dynamic configuration for cloud native Swift services

- **発表日**: 2026-06-01 (月曜日 20:00 JST) / 原文表記 Mon, 01 Jun 2026 11:00 +0000
- **カテゴリ**: 機能 (Feature / Configuration Library)
- **影響範囲**: Linux 上で Swift により本番サービスを運用する開発者。Kubernetes ConfigMap・環境変数・CLI 引数・YAML/JSON ファイルなど多様な設定ソースを扱うクラウドネイティブな Swift サービス。
- **核心要約** (本文ベース):
  - **何 (What)**: Swift サービスにおける設定管理を標準化する Swift Configuration ライブラリのパターン紹介。`ConfigReader`、`ReloadingFileProvider`、複数 ConfigProvider のスタックといった構成要素を提示しています。
  - **どのように (How)**: 複数の `ConfigProvider` を優先度順に並べ (例: CLI 引数 > 環境変数 > .env ファイル > インメモリ既定値)、`ConfigReader` に渡します。ドット (`.`) 表記のキーと `scoped(to:)` によりサブツリー単位のアクセスをサポートします。動的更新には `ReloadingFileProvider<YAMLSnapshot>` がファイル変更をポーリングしてスナップショットを更新し、Kubernetes では ConfigMap をボリュームマウントしてこのプロバイダに参照させます。YAML・JSON プロバイダは標準で提供され、コミュニティが TOML リーダーなどを追加できます。
  - **なぜ・効果 (Why / Impact)**: Swift サービスでこれまで ad hoc だった設定処理 (環境変数・ファイルパースを直接実装) を、宣言的・階層的・ホットリロード可能な方式へ移行させ、Prometheus・OpenTelemetry のように標準化された運用パターンを備えることを目指しています。
  - **主要データ**: サンプルコード内に `config.pollIntervalSeconds: 15` などのポーリング間隔値が明示されています。
