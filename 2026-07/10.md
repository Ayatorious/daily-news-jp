## 🟡 Priority 2 — Release / GA / Deprecated / EOL

### [CNCF] Navigating the ingress-NGINX retirement

- **発表日**: 2026-07-10 (金 05:45 JST / 原文 07-09 20:45 UTC)
- **カテゴリ**: サポート終了 (End of Life) / Ingress コントローラー移行 (ingress-nginx, Gateway API) — 本文中の「unpatched CVEs」は特定の CVE・セキュリティアドバイザリではなく、retirement 後のリスクへの言及であるため、P1 ではなく P2 (EOL) に分類
- **影響範囲**: Kubernetes SIG Network のコミュニティ管理 `ingress-nginx` コントローラーを使用しているクラスター。本文によると Ingress API 自体は引き続きサポートされ、EOL の対象は ingress-nginx コントローラーです。移行時、`nginx.ingress.kubernetes.io/*` アノテーションはすべて動作しません。
- **核心要約**:
  - 2026年3月に ingress-nginx コントローラーが retirement となり、継続使用した場合は未パッチ CVE への露出、機能アップデートの停止、コミュニティサポートの終了という運用リスクがあると指摘しています。
  - よくある誤解と異なり、Kubernetes Ingress API そのものが廃止されるわけではなく、EOL となるのはコミュニティが維持してきた ingress-nginx コントローラーであると明記しています。
  - 移行パスは2つで、(A) 既存の Ingress YAML を維持し ingress class のみを Contour (Envoy ベース) に差し替える lift-and-shift、(B) この機会に Gateway API へモダナイズする方法です。(A) の場合、nginx 専用アノテーションは手動での変換が必要です。
- **原文リンク**: https://www.cncf.io/blog/2026/07/09/navigating-the-ingress-nginx-retirement/
